# SkillVault — Editable Course Website

## Edit these first

### 1) Telegram username
Open:
`js/app.js`

Change:
`YOUR_TELEGRAM_USERNAME`

Example:
`skillvault_support`

Do NOT include @.

### 2) Add / edit courses
Open:
`data/courses.json`

Duplicate any course object and edit:
- title
- creator
- category
- price
- oldPrice
- badge
- image
- description
- tags

### 3) Course image
You can use:
- a direct image URL, or
- your own file path, e.g. `assets/my-course.jpg`

If using your own image, put the image inside the `assets` folder.
